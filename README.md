# Seam

> **Pre-alpha — under active development, not ready for production use.**

A fast, typed, capability-oriented IPC runtime for systems and applications.

Status: early research. An experimental three-process authority fabric
lives under `experiments/authority-fabric/` — not a stable API. A new
production workspace (`crates/seam-*`) is under construction and not yet
stable.

| Linux | under development |
